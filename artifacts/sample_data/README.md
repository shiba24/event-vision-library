# Sample data

Sample data and recordings used by the scripts in [`examples/`](../../examples).

## `sample.aedat4`

A short sample AEDAT4 recording from a DAVIS346 event camera, used by
[`examples/convert_aedat4_to_hdf5.py`](../../examples/convert_aedat4_to_hdf5.py)
and [`examples/read_aedat4.py`](../../examples/read_aedat4.py).

It is a trimmed clip of `test_data.aedat4`
from the [`neuromorphicsystems/aedat`](https://github.com/neuromorphicsystems/aedat)
project.
